1 프로젝트 개요
Executive Summary

1.1 프로젝트 배경

안산주성령교회는 문화선교를 핵심 전략으로 채택하여, 대중 문화 동아리 활동을 통해 일반인과 자연스럽게 접촉하고, 말씀으로 연결하며, 궁극적으로 교회 공동체로 이끄는 선교 모델을 운영하고 있습니다.

이를 체계적으로 지원하기 위한 디지털 플랫폼 'JS MISSION'을 기획·개발하였습니다.

1.2 프로젝트 정의

JS MISSION = 선교형 CRM + 동호회 운영 플랫폼

동아리는 수단이며, 사람 관리(선교 5단계 추적)가 핵심 목적입니다.

8 주요 기능 상세

8.1 생명 연결하기 (V3.0 신규)

각 동아리 상세 페이지에서 새로운 생명(신입생)을 동아리에 연결하는 핵심 선교 기능입니다.

필드설명
전도자 (연결자)본인 이름 또는 소개해준 분의 이름
신입생 (생명) *새로 연결할 분의 이름 (필수)
신입생 상황만남 경위, 현재 상황
운영자와 대화하기운영자에게 전할 메시지

등록 시 해당 동아리의 신입생(CRM)으로 자동 등록되어 파이프라인에 반영됩니다.

8.2 동아리 일정 달력 (V3.0 개선)

  • 월간 달력에 각 동아리 아이콘이 해당 날짜에 직접 표시
  • 날짜 클릭 → 해당일 동아리 목록 + 시간 상세 표시
  • 좌우 화살표로 전달/다음달 이동
  • 모바일 최적화: 아이콘 한줄 2개씩 배치

8.3 피드백 댓글 시스템 (V3.0 신규)

사용자 측관리자 측
피드백 작성 → 목록에서 펼침 → 관리자 답변 확인 → 추가 댓글 Admin → 피드백 관리 → 전체 목록 → 답변 작성

8.4 테스트 입장 (V3.0 신규)

로그인 화면 최상단에 이름만 입력하면 즉시 앱 체험 가능. 승인 절차 없이 자동 계정 생성.

8.5 동아리 운영방 (멤버 전용)

탭기능
일정회차별 일정 관리, 출석 체크
공지동아리 내부 공지사항
대화방실시간 채팅 (3초 폴링), 메시지 고정
자료방파일 업로드/다운로드
신입생신입생 CRM — 5단계 추적, 기도, 활동 기록

8.6 게시판 공통 기능

공지사항, 생명의 말씀, 자유게시판, Feedback 모든 게시판에서:

  • 글쓰기 (제목 + 본문)
  • ♡ 좋아요 (1터치)
  • 댓글 + 대댓글 (1단계 중첩)
  • 조회수 자동 카운트
