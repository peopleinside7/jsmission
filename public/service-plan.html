1 서비스 개요

JS MISSION은 안산주성령교회의 문화선교를 위한 통합 플랫폼입니다.

미션

대중 문화 동아리를 통해 일반인과 접촉하고, 말씀으로 연결하여, 교회로 이끄는 선교형 CRM + 동호회 운영 플랫폼

핵심 가치

항목설명
앱 명JS MISSION
소속안산주성령교회
목적문화선교 — 동아리 활동 → 말씀 연결 → 교회 연결
플랫폼반응형 모바일 웹앱 (PWA 지원 가능)

주요 기능 상세

생명 연결하기

각 동아리 상세 페이지에서 새로운 생명(신입생)을 동아리에 연결하는 기능:

  • 전도자(연결자) 이름
  • 신입생(생명) 이름
  • 신입생 상황 (만남 경위)
  • 운영자와 대화하기 (메시지)

동아리 일정 달력

월간 달력에 각 동아리 아이콘이 해당 날짜에 표시. 날짜 클릭 시 상세 일정(동아리명+시간) 확인. 좌우 화살표로 월 이동.

테스트 입장

로그인 화면 최상단에 이름만 입력하면 즉시 앱 체험 가능. 승인 절차 없이 자동 계정 생성.

6 선교 5단계 파이프라인

신입생의 선교 여정을 5단계로 추적합니다.

🎯 시도 (ATTEMPT)
→
☕ 전초 (PRELIM)
→
📖 말씀연결 (GOSPEL)
→
⛪ 예배참석 (WORSHIP)
→
🎓 수료 (COMPLETE)
단계코드의미색상
🎯 시도ATTEMPT전단지, 설문, 말 걸어보기 등 최초 접촉#5B9A6F
☕ 전초PRELIM식사/차 — 말씀 연결 위한 전 단계 만남#7BAA8E
📖 말씀연결GOSPEL노방, 전단지, 지인소개로 말씀 연결 (핵심)#2D7A3A
⛪ 예배참석WORSHIP주일 예배 참석#3D8B5A
🎓 수료COMPLETE정착, 양육 완료#1E5631

10 보안 및 인증

항목구현
비밀번호 암호화bcryptjs (saltRounds: 10)
JWThttpOnly Cookie, Access 30분, Refresh 7일
자동 토큰 갱신25분 인터벌 자동 refresh
로그인 잠금5회 실패 → 15분 잠금
파일 업로드20MB 제한, 확장자 화이트리스트 (SVG 차단)
Path Traversal파일 서빙 시 resolve() + startsWith() 검증
인증 미들웨어Next.js Middleware로 공개/보호 경로 분리
권한 검증동아리 멤버 검증, Admin 전용 API 보호
입력 검증텍스트 길이 제한 (게시글 10000, 댓글 2000, 채팅 500자)
한글 인코딩request.text() + JSON.parse() 방식 (WASM 호환)
